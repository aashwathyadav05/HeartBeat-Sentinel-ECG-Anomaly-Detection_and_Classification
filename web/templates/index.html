HeartBeat Sentinel

Explainable ECG Anomaly Detection using 1D Convolutional Autoencoder

Educational Research Prototype - Not for Clinical Use

Overview

Project Information

Objective: Detect ECG anomalies by learning normal patterns with a 1D Convolutional Autoencoder and flagging deviations via reconstruction error.

Approach: Normal-only training (class 1.0) → Reconstruction MSE → Threshold from validation normals

Dataset: ECG5000 (UCR) - 140-sample ECG segments

Model: 1D Convolutional Autoencoder (PyTorch)

Methodology & Limitations

Methodology

  • Normal-only Training: Autoencoder learns to reconstruct class 1.0 segments; anomalies produce higher reconstruction error.
  • Architecture: 1D Convolutional Autoencoder with encoder-decoder structure and latent bottleneck.
  • Reconstruction Error: Segment-level MSE = mean((x - x̂)²).
  • Threshold Selection: Computed from normal validation samples only (e.g., 95th percentile) - not optimized on test set.
  • Evaluation: Tested on untouched test set with precision, recall, specificity, F1, AUROC.

Limitations

  • Educational research prototype only - not a clinical diagnostic system
  • Detects deviation from learned normal patterns, does not diagnose specific arrhythmias
  • Threshold-based approach has sensitivity/specificity trade-offs
  • Evaluated on preprocessed ECG5000 benchmark - may not generalize to raw clinical data
  • Class overlap can cause false positives and false negatives
  • No treatment recommendations provided
